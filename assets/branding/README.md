# Логотип и иконки

Знак v8-chroma — призматическая C в сине-фиолетовой палитре.
SVG-мастера содержат редактируемую геометрию; скрипт экспортирует из них
растровые варианты и иконки приложения.

| Файл | Использование |
|---|---|
| `mark.svg` | Основной цветной знак, прозрачный фон |
| `logo-dark.svg` | Знак и тёмная надпись для светлого фона |
| `logo-light.svg` | Знак и белая надпись для тёмного фона |
| `app-dark.svg` / `app-light.svg` | Иконка на тёмной / светлой плашке |
| `mark-mono-dark.svg` / `mark-mono-light.svg` | Одноцветные варианты |
| одноимённые PNG | Растровые варианты с прозрачностью |

Палитра: cyan `#00C8DB`, blue `#167CEF`, indigo `#2636B9`, violet `#7637F2`.
В интерфейсе используются нейтральные тёмные поверхности, светлый фиолетовый
акцент `#BCA7FF` для действий и выбора, cyan для фокуса клавиатуры.
Зелёный обозначает успешное состояние и включённое наблюдение. Цвета
предпросмотра редактора задаёт выбранный пресет независимо от оформления
приложения. Переменные палитры находятся в `../../ui/src/style.css`.

В словесном знаке используется системный Segoe UI Semibold; файлы шрифта
не копируются в проект и не распространяются.

Иконки приложения находятся в `../../ui/src-tauri/icons/`: PNG 16–512 px,
многоразмерный ICO и `tray.rgba` 32×32. SVG-мастер не содержит встроенных bitmap.

Регенерация:

```powershell
python -m pip install -r scripts/requirements-branding.txt
python scripts/build_branding.py
```

Предпросмотр: `../../design/branding-preview.png`.
