The palette is adapted to the 17 roles of the EDT plugin. Line and hover alpha
are composited on editor and panel backgrounds. Directive uses the constant
color; warning uses the upstream warning validation border color.
v8-chroma uses the RGB palette as input and independently maps observed
1C Designer drawing colors to the available roles. It does not implement a
complete token-level Dracula theme. No upstream icons or fonts are included.

Native release build: CMake/Ninja with MSVC on Windows x64. Zig 0.15.2 and
MinGW are optional developer toolchains. Compilers are not distributed.
Runtime/library notices are retained in licenses/.
DarkConfig source code and binaries are not included or used.

Additional EDT adaptations in this release: Ayu Dark, Darcula, GitHub Dark
Default, Monokai, Night Owl, Noctis Minimus, One Dark Pro, Shades of Purple,
Visual Studio Dark (C/C++), Winter Is Coming Dark Blue.
Unmodified palette inputs: palettes/edt/palettes/.
All supplied upstream notices and licenses: palettes/edt/third-party-notices.txt
and palettes/edt/licenses/. File hashes and archive provenance:
palettes/edt/provenance.json. Darcula and Monokai are supplied as MIT-licensed
palette data by EDT Themes; the archive does not document separate upstream
sources for these two palettes. No IntelliJ IDEA or Sublime Text code is used.
Generated JSON and the Rust render mapping adapt selection, hover and other
states for 1C controls; the original palette inputs remain unchanged.
