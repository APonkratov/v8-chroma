# Лицензии

Собственный код v8-chroma — [MIT](../LICENSE). Для сторонних материалов
сохраняются их лицензии и авторство.

## Состав

- Палитры EDT Themes: исходные данные, лицензии и уведомления в `assets/palettes/`.
  Для отдельно добавленных светлых тем там же указаны исходники VS Code и Primer.
- Лицензии Rust/npm-зависимостей, включаемых в уведомления приложения.
- Уведомления стандартной библиотеки Rust, native runtime и WebView2 SDK.

Приложение использует данные палитр из EDT Themes, а не Java-код плагина.
Исходные сведения об архиве и ревизиях сохранены рядом с палитрами.

## Уведомления для выпуска

После `cargo fetch --locked` и `npm ci`:

```powershell
python scripts/collect_licenses.py
```

Скрипт автоматически создаёт `build/licenses/THIRD-PARTY-NOTICES.txt`.
Он вызывается при сборке релиза и собирает обычные Rust-зависимости Windows
и production-зависимости npm. Ветки только для сборки и тестов исключаются;
это перечень зависимостей по манифестам, а не анализ машинного кода EXE.
Для MPL-компонентов добавляются ссылки на исходники точных версий.

При добавлении зависимости проверьте совместимость её лицензии.
Уведомления формируются из актуальных lock-файлов во время сборки релиза.

Если в пакете отсутствует текст лицензии, используется сохранённый текст
для этой версии из `overrides/`. Источники этих файлов указаны в `sources.json`.
Если текста нет и там, выпуск останавливается с названием пакета.

Готовый файл уведомлений сопровождает оба EXE. Исходные тексты лицензий и
уведомлений авторов не удаляются. Платформа 1С и WebView2 Runtime в поставку
не входят; Runtime для GUI устанавливается отдельно.
