# Светлые палитры

Источники, закреплённые ревизии, исходные значения ролей и поправки
перечислены в [карте палитр](../assets/palettes/light-sources/port-provenance.json).
[EDT Themes](https://github.com/litonchik/ones_edt_themes) помог сопоставить роли
с элементами 1С. Отдельные палитры Visual Studio Light Modern и Visual Studio
Light (C/C++) соответствуют разным оригиналам Microsoft.

Непрозрачные поверхности сохраняют исходный RGB. Цвета с альфа-каналом сведены
с фоном, на котором они рисуются: например, выделение Noctis берётся из редактора
оригинальной темы. Если контраст текста на поверхности ниже 4,5:1, каналы RGB
пропорционально затемняются до порога. Контраст проверяется по месту применения:
синтаксис на фоне редактора и текущей строки, выделенный текст на выделении,
подписи и ссылки на фоне соответствующих панелей. У Winter Light основной синий
текст слегка темнее оригинала, поскольку Конфигуратор рисует им и обычный текст,
и подписи на выделенных ячейках и результатах поиска.

Отдельно вычисляется цвет сетки табличного документа. Когда исходный цвет
текущей строки слишком близок к выделению (например, в Noctis Lux),
затемняется только сетка на величину, необходимую для различимости.
Палитра редактора сохраняет оба исходных цвета.

Для расширенной подсветки TextMate светлые темы используют цвета функций,
параметров, переменных и типов из оригинальных правил. Для вложенных запросов
используются близкие оригинальные роли ключевых слов и функций. Когда исходная
тема задаёт двум категориям один цвет, например параметрам и переменным Noctis,
они сохраняют общий оттенок. Для мелкого кода в светлых темах порог TextMate
составляет 6:1 на основном фоне редактора и 5,5:1 на фоне текущей строки.
Цвета, уже проходящие обе проверки, остаются исходными.
Для категорий, которые сливаются после затемнения, используются разные оттенки
из той же исходной палитры. В Ayu Light имена функций выделены синим
рядом с медными ключевыми словами. Параметры бирюзовые, числа фиолетовые.

## Строки и числа в модулях

Путь в Конфигураторе: **Сервис → Параметры → Модули → Редактирование →
Выделение цветом синтаксических конструкций**. Платформа позволяет отдельно
задать цвета для «Константы типа „Число“» и «Константы типа „Строка“».
В тестовой базе на 8.3.27.2325 оба поля показывали RGB 0, 0, 0.
[Руководство 1С](https://kb.1ci.com/1C_Enterprise_Platform/Guides/Developer_Guides/1C_Enterprise_8.3.24_Developer_Guide/Chapter_36._Service_features/36.2._Setting_Designer_parameters/36.2.3._Modules/)
также описывает независимые настройки для синтаксических конструкций.

В режиме «Расширенная» TextMate распознаёт строки и числа как разные
категории и использует для них отдельные цвета палитры. Это работает в
модулях и в сравнении модулей на поддерживаемых сборках. Предпросмотр
показывает те же цвета. Вызовы пользовательских процедур, функций и методов
получают цвет имён функций. Для встроенных функций сохраняется своя роль.
В режиме «Стандартная» действует подмена RGB:
если строки и числа отрисованы штатным чёрным, они получают общий цвет.
Цвета в общих настройках пользователя при применении тем не меняются.
