# Шрифты интерфейса, редактора и лигатуры

## Шрифт интерфейса

На вкладке «Темы» поле «Шрифт интерфейса» меняет меню, дерево, панели и
стандартные элементы Конфигуратора. По умолчанию выбран **Segoe UI Variable Small**.
Если он не установлен, используется Segoe UI с предупреждением в карточке процесса;
если нет обоих семейств, сохраняется штатный шрифт 1С. Другие отсутствующие
семейства не подменяются молча. Шрифты не скачиваются и не входят в сборку.

Выбор сохраняется и сразу меняет предпросмотр. Он подчиняется общему флагу
автоприменения: при выключенном флаге нажмите «Применить оформление» либо
«Применить» в нужной карточке Конфигуратора. Пункт «Как в 1С» возвращает штатный
шрифт без перезапуска, сохраняя последнее выбранное семейство в настройках.
Размер, жирность и курсив элементов задаёт сама 1С. Шрифт и размер редактора
настраиваются отдельно.

Меню, дерево и панели обновляются в открытом процессе. Уже открытые модальные
диалоги могут хранить старые размеры подписей: при обрезании текста переоткройте
такой диалог. Менеджер показывает предупреждение, если во время применения
были открыты диалоги. Это не требует закрытия Конфигуратора.

`src/ui_fonts/platform.rs` извлекает встроенную `UiFontEngine.dll`, проверяет
идентичность процесса и фиксирует результат в отдельной сессии. Движок меняет
стандартные интерфейсные алиасы шрифтов. Преобразования явно заданных шрифтов
документов и шрифта редактора остаются независимыми. Пересчёт метрик запускается
штатным `kDefaultStyleChangedEvent` на GUI-потоке 1С. API определяется по структуре
кода и ссылке на экспорт GUID, без фиксированных адресов и списка версий.
Если API не распознан, остаётся штатный шрифт с предупреждением; тема и редактор
применяются независимо. Незавершённые вызовы и ошибки не повторяются до штатного
перезапуска этого Конфигуратора. Файлы платформы, база и настройки Windows не меняются.

Схема настроек 4 добавляет `ui_font: { enabled, family }`. Миграция схем 1/2/3
сохраняет точную резервную копию, тему, флаг автоприменения, значки и шрифт
редактора; интерфейс получает новый шрифт по умолчанию.

CLI: `settings set --ui-font "Segoe UI Variable Small"` либо
`settings set --native-ui-font`. Эти команды только сохраняют настройки;
применение выполняется `attach`, `apply-all` или наблюдателем с включённым
автоприменением.

## Шрифт редактора

На вкладке «Темы» доступны установленные семейства и размер 8–32 pt с шагом 0,5.
Моноширинные показываются первыми, затем пропорциональные; внутри групп семейства
сортируются по имени, а популярные шрифты для кода поднимаются в начало своей группы.
Шрифты не скачиваются и не поставляются с приложением.
Выбор сохраняется и обновляет общий предпросмотр. Применение темы, значков
и шрифта подчиняется одному флагу в «Настройках»; при выключенном флаге
используется «Применить оформление» или кнопка в карточке процесса.

Для редактора режим «Как в 1С» выключает подмену. При миграции настроек из схем 1/2
сохраняется точная резервная копия, а управление шрифтом остаётся выключенным.
Для подмены исходное семейство в параметрах редактора 1С должно быть Courier New.
Размер задаётся в пунктах с учётом DPI; масштабирование редактора средствами 1С
не является частью управления размером менеджера.

## Устройство

`src/fonts/platform.rs` получает локальный каталог через GDI, проверяет семейство,
идентичность и владельца процесса, извлекает встроенную `FontProbe.dll` в отдельный
неизменяемый каталог и ведёт сессию по PID и времени создания процесса.
При обновлении движка уже открытый Конфигуратор требуется штатно перезапустить.
Незавершённые вызовы не повторяются автоматически.
Отказ загрузки DLL, чтения экспортов, запроса возможностей или применения шрифта
сохраняется как завершённая ошибка с исходной диагностикой. Если API шрифта недоступен,
сохраняется отдельный результат с предупреждением: тема работает независимо,
а выбор «Как в 1С» не требует повторного обращения к несовместимому API.

`native/src/font_probe.cpp` перехватывает преобразование шрифта в `LOGFONTW`
в `grphcs.dll`. Меняются семейство Courier New и размер, после чего сама платформа
измеряет и рисует текст. Файлы установки 1С не изменяются.

`font_discovery.h` ищет механизм обновления шрифта редактора по структуре
инструкций, связям вызовов и таблицам методов. Проверок номера версии, хеша
платформы и фиксированных адресов функций нет. Перед вызовом проверяется
ожидаемая структура API. Обновление выполняется в потоке интерфейса и затрагивает
только шрифт: текст, Undo, каретка, выделение и свёрнутые блоки остаются в редакторе.
Если обновление не распознано, подмена применяется к новым редакторам,
а менеджер предлагает переоткрыть модуль. Тема применяется независимо.

`font_ligatures.h` выделяет последовательности ASCII-операторов в отдельные
фрагменты Uniscribe с `fMergeNeutralItems`. Это позволяет включить контекстные
подстановки и рядом с кириллицей. Анализ остального текста сохраняется;
RTL-фрагменты пропускаются. При нехватке места или ошибке используется исходный
результат разбиения. Глифы, позиции и кластеры рассчитывает штатный Uniscribe.
При отсутствии нужного импорта механизм лигатур не подключается.

Отдельного переключателя лигатур нет: набор сочетаний определяется семейством.
Предпросмотр WebView2 и редактор 1С используют разные механизмы отрисовки,
поэтому их результат может отличаться. Журнал сессии хранит состояние и счётчики;
текст редактора и дампы памяти не записываются.

## Проверки

| Платформа Windows x64 | Смена семейства и размера | Выделение, несохранённый текст, Undo | Возврат шрифта 1С |
|---|---|---|---|
| 8.3.26.1656 | Проверено | Проверено | Проверено |
| 8.3.27.2325 | Проверено | Проверено | Проверено |
| 8.5.1.1529 | Проверено | Проверено | Проверено |
| 8.5.4.1878 | Проверено, включая два редактора | Проверено | Проверено |

Лигатуры JetBrains Mono Medium визуально проверены на 8.3.27 и 8.5.4 в текстовом
документе с режимом «Встроенный язык»: условия с кириллицей, строки, комментарии,
ввод между символами лигатуры и выделение пары `<=`. На 8.3.27 проверена отмена
правки, сделанной до смены размера. Это не полная матрица всех редакторов и версий.

Пропорциональные Arial 16 pt и Segoe UI 18 pt проверены на 8.3.27 и 8.5.4 в том же
BSL-режиме: ввод между узкими и широкими символами, выделение `iiiWWW`, сохранение
свёрнутой процедуры и Undo через смену семейства/размера, возврат к JetBrains Mono
и параметрам 1С. В Uniscribe отдельно проверены ширина и позиции каретки для Arial
и Segoe UI. Пропорциональные шрифты сохраняют свою разную ширину символов;
выравнивание столбцов пробелами зависит от выбранного семейства.

`python scripts/build.py check` запускает `font_shaping` с Consolas без установки 1С.
Тест сравнивает ширину и каждую позицию каретки до и после изменения разбиения,
в том числе в смешанных строках. Дополнительный запуск с установленным семейством:

```text
tests/fixtures/font_shaping.exe "JetBrains Mono Medium"
tests/fixtures/font_shaping.exe "Cascadia Code"
tests/fixtures/font_discovery_test.exe "<каталог платформы>/bin"
```

Для JetBrains Mono Medium и Cascadia Code подтверждены подстановки девяти
образцов операторов и неизменная геометрия. `font_discovery_test` отображает DLL
установленной платформы без выполнения `DllMain`, проверяет обнаружение API
и отказ при изменённой структуре кода. Базы и двоичные файлы 1С не распространяются.

## Проверка интерфейсного шрифта

Интеграция проверена на 1С 8.3.27.2325 x64 в отдельной тестовой базе.
В одном процессе после позднего подключения движка переключены Variable Small,
штатный шрифт, Roboto и снова Variable Small. Несохранённый текст и выделение
сохранились; Undo/Redo работали после переключений. Шрифт редактора JetBrains Mono
успешно включён уже после загрузки движка интерфейса. В табличном документе
проверены явные Arial, MS Sans Serif (жирный) и Microsoft Sans Serif (курсив):
переключение интерфейса сохранило их начертания, размер и ширину текста.

При выключенном автоприменении выбор через GUI сохранился и изменил только
предпросмотр; счётчик штатных уведомлений оставался прежним до «Применить»
в карточке выбранного процесса. Rust-тесты проверяют эту политику также при
включённом наблюдении, миграцию схемы 3 с точной резервной копией, отсутствующие
семейства, протокол UTF-16 и запрет повторения незавершённых вызовов.
`ui_font_policy_test` проверяет алиасы, сохранение размеров и стилей, символы
и возврат штатного режима; запускается обычной командой `scripts/build.py check`.
Дополнительно проверены все установленные платформы x64:

| Платформа | Segoe UI Variable Small | Возврат «Как в 1С» | Roboto |
|---|---|---|---|
| 8.3.26.1656 | Горячее применение | Без перезапуска | Горячее применение |
| 8.3.27.2325 | Горячее применение | Без перезапуска | Горячее применение |
| 8.5.1.1529 | Горячее применение | Без перезапуска | Горячее применение |
| 8.5.4.1878 | Горячее применение | Без перезапуска | Горячее применение |

В каждой тестовой базе дерево и меню проверены визуально. Шаг строк дерева
менялся с 19 до 21 px при выборе Variable Small и возвращался при отключении.
PID и время создания процесса между переключениями не менялись.

В ранней сборке 8.5.1/8.5.4 оставались со штатным шрифтом: распознавался только
обычный вызов уведомления, тогда как компилятор использовал хвостовой переход
после восстановления стека. `ui_font_discovery.h` теперь проверяет обе формы,
связь с экспортированным GUID, границы функции и однозначность источника.
Фиксированные адреса и ограничения по номеру версии не добавлялись.

`ui_font_discovery_test <каталог платформы>/bin` отображает установленный core
без выполнения DllMain, проверяет обнаружение, отказ при неверном GUID и
изменённом слоте вызова, затем восстанавливает образ в памяти. Проверен на
всех четырёх версиях; двоичные файлы платформы в репозиторий не входят.
При обновлении встроенной DLL уже подключённый к старому движку процесс нужно
однократно штатно переоткрыть. После этого выбор шрифта применяется горячо.
На 8.5.4 дополнительно проверены несохранённый текст, выделение, Undo/Redo и
позднее включение JetBrains Mono через приложение вместе с Roboto и новыми значками.
Другие DPI требуют отдельной проверки.
